# Amuria — Portafolio

Portafolio de María José Cifuentes (diseñadora gráfica, Medellín).
Sitio estático de un solo archivo: abre `index.html` en el navegador.

## Publicar con GitHub Pages
1. Sube este repositorio a GitHub.
2. En el repositorio, ve a Settings > Pages.
3. En "Build and deployment", elige la rama `main` y la carpeta `/ (root)`.
4. El sitio quedará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
